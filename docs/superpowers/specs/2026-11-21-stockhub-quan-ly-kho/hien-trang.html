2. Hiện trạng hệ thống

Đánh giá xuất phát điểm của kho mã nguồn, đối chiếu với các yêu cầu kỹ thuật Enterprise của AGENTS.md.

Kết luận hiện trạng: Dự án ở trạng thái Greenfield (khởi tạo từ đầu). Mã nguồn mới có file quy chuẩn AGENTS.md và kho lưu trữ Git cục bộ, chưa có cấu trúc thư mục source code hay cơ sở dữ liệu. Toàn bộ giải pháp sẽ được thiết kế chuẩn chỉnh từ nền móng theo Clean Architecture (.NET 10) và Feature-based (React).

Khảo sát mã nguồn hiện có

Kiểm tra thư mục làm việc tại thời điểm khảo sát (21/11/2026):

Khoảng trống kỹ thuật (Gap Analysis)

Đối chiếu giữa yêu cầu đề tài ĐT07 và quy chuẩn kỹ thuật bắt buộc với xuất phát điểm hiện tại:

Hạng mục Mục tiêu cần đạt Khoảng trống cần bổ sung
Kiến trúc Backend Clean Architecture (.NET 10), CQRS MediatR, FluentValidation, EF Core 10. Khởi tạo trọn bộ cấu trúc solution, cài đặt packages cần thiết, cấu hình Dependency Injection và Middleware RFC 9457 ProblemDetails.
Xác thực & Phân quyền JWT Bearer + Refresh Token, Swagger UI có nút Authorize, 3 vai trò (Admin, WarehouseStaff, Accountant). Hiện thực dịch vụ cấp token, bảng lưu RefreshToken, Swagger Gen cấu hình SecurityScheme Type Http Bearer.
Quy tắc 1: Tồn kho không âm Optimistic Concurrency kiểm tra số lượng khả dụng, bọc Transaction chống race condition. Tạo bảng Inventories với cột RowVersion (hoặc xmin), viết Unit Test kiểm thử 100 tác vụ xuất đồng thời.
Quy tắc 2: Phiếu đã duyệt cấm sửa Domain State Machine: Chỉ trạng thái Draft mới được sửa/xóa, từ chối mọi yêu cầu nếu đã là Approved/Rejected. Thiết lập quy tắc nghiệp vụ trong Entity Voucher, viết các Unit Test Assert lỗi khi cố tình cập nhật phiếu đã duyệt.
Quy tắc 3: Link duyệt dùng 1 lần Cơ chế Secure Token có trường UsedAt, xử lý đơn nguyên trong DB Transaction. Thiết kế bảng ApprovalTokens, viết endpoint sinh link và endpoint xác thực duyệt phiếu một lần.
Frontend React Giao diện điều khiển kho, tạo phiếu, hiển thị nút "Sao chép link duyệt", trang Kế toán duyệt phiếu 1 lần. Dựng layout, TanStack Query, React Hook Form + Zod, axios interceptor hỗ trợ refresh token.
DevOps & Kiểm thử docker compose up --build chạy toàn bộ hệ thống; Unit test có Code Coverage; GitHub Actions CI. Viết Dockerfile cho WebApi và Frontend, file docker-compose.yml, cấu hình test runner (Coverlet) và file workflow YAML.

Định hướng thiết kế từ hiện trạng

Do là dự án mới hoàn toàn (Greenfield):

  • Thuận lợi lớn: Không bị vướng nợ kỹ thuật (technical debt), không phải tương thích ngược với cơ sở dữ liệu cũ, có thể tuân thủ 100% chuẩn mực khắt khe của AGENTS.md ngay từ commit đầu tiên.
  • Kế hoạch: Tiến hành phân tích miền (Domain Analysis) $\rightarrow$ Thiết kế API & Database $\rightarrow$ Lập kế hoạch phân rã theo lát dọc (Vertical Slice) để triển khai từng tính năng hoàn chỉnh từ Backend sang Frontend.
