8. Mockup Giao diện Hệ thống

Bản vẽ giao diện React + Tailwind CSS các màn hình trọng tâm phục vụ quy trình nhập xuất và phê duyệt một lần.

Trọng tâm Demo 5–10 phút: Mockup tập trung làm nổi bật luồng thao tác của 3 vai trò: Đăng nhập nhanh $\rightarrow$ Nhân viên tạo phiếu xuất $\rightarrow$ Bấm nút "Tạo & Sao chép link duyệt" $\rightarrow$ Kế toán mở link duyệt thành công $\rightarrow$ Mở lại link lần 2 nhận thông báo chặn lỗi.
